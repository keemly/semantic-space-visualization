# semantic-space-visualization

# Визуализация семантических пространств текстовых данных

## Описание проекта

Данный репозиторий содержит курсовую работу по теме **«Визуализация семантических пространств»** в рамках дисциплины **«Машинное обучение в семантическом и сетевом анализе»**.

Цель работы состоит в сравнительном анализе способов представления коротких текстов и исследовании того, как различные модели формируют внутренние семантические пространства. В качестве практической задачи рассматривается многоклассовая классификация коротких новостных текстов.

В работе используются как векторные, так и графовые подходы к анализу текстовых данных. Помимо оценки качества классификации, проводится визуальный и количественный анализ структуры получаемых представлений.

## Используемый набор данных

В качестве набора данных используется **AG News** — корпус коротких новостных текстов, размеченных по четырём тематическим категориям:

- World;
- Sports;
- Business;
- Sci/Tech.

Датасет загружается автоматически с помощью библиотеки `datasets`, поэтому вручную скачивать данные не требуется.

## Основные задачи работы

В рамках проекта выполняются следующие этапы:

1. Загрузка и предварительный анализ датасета AG News.
2. Предобработка текстовых данных.
3. Формирование различных представлений текста:
   - TF-IDF-представление;
   - эмбеддинги Sentence-BERT;
   - последовательностное представление для BiLSTM.
4. Обучение и сравнение моделей классификации:
   - TF-IDF + MLP;
   - Sentence-BERT + MLP;
   - BiLSTM.
5. Оценка качества моделей по метрикам:
   - Accuracy;
   - Macro-F1;
   - Macro-Precision;
   - Macro-Recall.
6. Визуализация семантических пространств с помощью:
   - PCA;
   - t-SNE;
   - UMAP.
7. Подбор параметров визуализации по Silhouette Score.
8. Построение kNN-графов скрытых представлений.
9. Анализ графовой гомофилии как дополнительной характеристики структуры семантического пространства.
10. Интерпретация полученных результатов.
